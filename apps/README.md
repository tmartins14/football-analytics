# apps

Consumers of `libs/statsbomb` (Python data layer) and `libs/footballd3`
(JS viz layer) that are their own deployable/runnable thing, rather than
library code or one-off analysis.

Currently empty — reserved for future non-AI deployable apps. AI-engineering
features live under `ai/` instead (see `ai/README.md`). The existing legacy
dashboard (`pages/match-analysis/`) predates this convention and stays where
it is for now.
